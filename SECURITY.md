# Security

## What Aven holds

Nothing of value. There are no accounts, no wallets, no keys and no deposits. aUSD exists only in each visitor's
browser storage. The site is static: no server of its own receives anything a visitor types.

## What to report

- A way to make the site run script it didn't ship (XSS), for example through an address pasted into Mirror or a
  command typed into the command line.
- A dependency or third-party script that could be swapped for something malicious.
- Anything that could trick a visitor into thinking Aven asks for funds, a wallet connection or a key. Aven never
  does.

## How

Open a private report through GitHub: **Security → Report a vulnerability** on this repository. Please don't open a
public issue for it. Expect a first answer within a few days.

## Scams

Aven has nothing to buy and nothing to deposit. Real-money trading is planned for later and has no date. Anyone
offering aUSD, an Aven token, early access for a fee or asking for your seed phrase is not Aven.
